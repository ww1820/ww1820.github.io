rclcpp::Node 类 API 速查 ​

rclcpp::Node 是写 ROS 2 节点代码的核心类：通信实体（publisher/subscription/service/client/timer）、参数、图查询、回调组全部从它创建。本文按功能域整理其公开 API，每个接口附签名与注意事项，作为写节点代码时的速查表。基于 rclcpp 当前主线接口，未逐一区分发行版差异。

重要边界与陷阱 ​

  1. 名称/主题 remap：get_*_by_node 系列不应用 remap；get_publishers_info_by_topic 传入相对名会用 effective namespace 扩展但并不 remap——写监控/诊断代码时先确认想查的是 ROS 名还是实际名
  2. 指针/引用生命周期：不要缓存 get_name() 返回的 const char* 超过 node 生命周期
  3. 参数回调副作用限制：on_set_parameters 回调里禁止修改参数或注册/移除回调（会抛异常）；多个回调按注册逆序执行
  4. 线程安全：部分访问（如 for_each_callback_group）标注线程安全；对 node 内部状态的复杂并发操作应谨慎，优先使用官方线程安全接口与 callback_group/executor 模型
  5. 异常语义：很多查询/创建操作会在底层 rcl/rmw 失败时抛 std::runtime_error 或更专门的异常；客户端代码应准备捕获或让异常冒泡到合适位置
  6. 泛型 API：create_generic_* 在运行时解析类型，消息包不在 AMENT 前缀路径或解析失败会抛异常；适合运行时插件或类型无编译期依赖的场景
