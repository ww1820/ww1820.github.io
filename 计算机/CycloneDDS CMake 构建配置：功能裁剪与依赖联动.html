CycloneDDS CMake 构建配置：功能裁剪与依赖联动 ​

Eclipse Cyclone DDS 使用 CMake 构建。除了标准的 CMAKE_BUILD_TYPE 等选项，项目提供了一组 -D 标志控制功能模块的编译、外部依赖的查找与特定 QoS 策略的支持。合理配置这些选项可以缩小二进制体积、适配嵌入式环境。这篇文章按用途分组整理常用选项，并给出三种典型场景的组合示例。

构建目标与工具配置 ​

选项 说明
-DBUILD_EXAMPLES=ON 构建示例程序，适合学习 API 或验证安装
-DBUILD_TESTING=ON 构建测试套件。注意：会强制导出库的所有符号，可能增大二进制并影响链接行为
-DBUILD_IDLC=NO 不构建 IDL 编译器 idlc。影响：无法编译新的 IDL 文件，依赖 IDL 的示例、测试与 ddsperf 都无法构建
-DBUILD_DDSPERF=NO 不构建 ddsperf 性能测量工具（基准测试与性能分析用）
-DBUILD_IDLC_XTESTS=NO 不构建 IDL 编译器的额外测试集。机制：运行时用 C 后端动态编译 IDL 并构建测试程序。限制：不支持 Windows

外部依赖与核心功能 ​

安全与加密（OpenSSL） ​

选项 说明
-DENABLE_SSL=NO 不查找 OpenSSL：移除 TLS/TCP 传输支持，不构建身份验证与加密的安全插件。默认 AUTO（检测到即启用）
-DENABLE_SECURITY=NO 不构建安全接口与钩子。即使 ENABLE_SSL=NO，理论上仍可启用此项以加载第三方安全插件，但通常两者配合使用

共享内存零拷贝（Iceoryx） ​

选项 说明
-DENABLE_ICEORYX=NO 不查找 Eclipse Iceoryx，禁用同机进程间零拷贝共享内存通信。默认 AUTO

QoS 策略与协议特性裁剪 ​

资源受限的嵌入式环境可以按需禁用：

选项 功能 依赖/联动限制
-DENABLE_LIFESPAN=NO 排除 Lifespan QoS（数据有效期） 无
-DENABLE_DEADLINE_MISSED=NO 排除 Deadline QoS（截止期限） 无
-DENABLE_TYPELIB=NO 排除类型库支持 必须同时 -DENABLE_TYPE_DISCOVERY=NO -DENABLE_TOPIC_DISCOVERY=NO
-DENABLE_TYPE_DISCOVERY=NO 排除类型发现与类型兼容性检查（大部分 XTypes 功能） 必须同时 -DENABLE_TOPIC_DISCOVERY=NO
-DENABLE_TOPIC_DISCOVERY=NO 排除主题发现支持 无独立强依赖，常被上面两项联动
-DENABLE_SOURCE_SPECIFIC_MULTICAST=NO 禁用源特定多播（SSM） QNX 平台建议同时禁用 IPv6
-DENABLE_IPV6=NO 禁用 IPv6 QNX 平台建议同时禁用 SSM

配置组合示例 ​

最小化嵌入式构建 ​

资源极度受限、只需要基本发布/订阅：

bash
cmake -B build \
  -DCMAKE_BUILD_TYPE=Release \
  -DBUILD_EXAMPLES=OFF \
  -DBUILD_TESTING=OFF \
  -DBUILD_DDSPERF=OFF \
  -DENABLE_SSL=NO \
  -DENABLE_ICEORYX=NO \
  -DENABLE_SECURITY=NO \
  -DENABLE_LIFESPAN=NO \
  -DENABLE_DEADLINE_MISSED=NO \
  -DENABLE_TYPE_DISCOVERY=NO \
  -DENABLE_TOPIC_DISCOVERY=NO \
  -DENABLE_IPV6=NO

需要完整的认证、加密、访问控制：

bash

高性能同机通信构建 ​

主要场景是单节点内多进程通信：

bash
cmake -B build \
  -DENABLE_ICEORYX=ON \
  -DBUILD_EXAMPLES=ON

3

前提：系统已安装 Eclipse Iceoryx 库。构建出的库配合 XML 配置里的 PSMX 接口启用共享内存传输。

注意事项 ​

  1. 依赖连锁：禁用 BUILD_IDLC 会导致依赖代码生成的 BUILD_EXAMPLES、BUILD_TESTING、BUILD_DDSPERF 无法构建。通常保留 IDLC，或手动预生成代码。
  2. 类型系统完整性：ENABLE_TYPE_DISCOVERY=NO 会严重影响动态类型处理能力，应用依赖 XTypes 特性时不要禁用。
  3. 平台特异性：QNX 等实时系统上，网络协议栈的实现可能要求同时禁用 IPv6 与源特定多播，以具体平台的构建文档为准。

要点 ​

  • 三类选项各管一段：BUILD_* 管工具与测试，ENABLE_SSL/SECURITY/ICEORYX 管外部依赖特性，ENABLE_* QoS 裁剪管二进制体积。
  • 类型相关三个选项（TYPELIB/TYPE_DISCOVERY/TOPIC_DISCOVERY）有强制联动关系，单禁一个会配置失败或行为不一致。
  • 嵌入式最小集 = 关工具 + 关安全 + 关 iceoryx + 裁 QoS + 关 IPv6，但 XTypes 依赖方要留意类型发现的取舍。
