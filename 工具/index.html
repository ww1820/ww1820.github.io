工具 ​

工具类成品文章（教程手册、效率工具），从 1-知识 的素材重写整理而来。

  • grep 遇到二进制数据：Binary file matches 提示的成因与处理 —— grep 检测到非文本字节后抑制输出的默认行为、非文本字节被当作行终止符的行尾锚定陷阱、-a/--binary-files=text/strings/-I 四种处理方式与各自代价
  • PlantUML 中文字体设置：skinparam 与 style 两种写法 —— 默认字体缺中文字形的乱码成因、skinparam defaultFontName 与新版 style 两种写法、字体名须与系统安装完全一致（plantuml.com/font 查询）、服务器装 fonts-noto-cjk 的三步排查
  • makeself 自解压打包：把整个目录打成单个 run 文件 —— 目录打成自解压 .run 的完整流程：打包参数与 LSM 元数据、--check/--keep/--list/--target 用户侧命令、默认嵌入 MD5+CRC 的校验机制与不加密的边界
  • shc 将 Shell 脚本编译为二进制：安装、原理与安全边界 —— 脚本包装成 ELF 二进制的基础混淆：-f/-o 编译流程与中间文件清理、运行时按原脚本 shebang 调解释器喂 stdin 的原理、可被逆向恢复的安全边界与 makeself 选型
  • GDB 生成 coredump：抓取运行中进程的内存快照 —— 未崩溃进程的 generate-core-file/gcore 三种快照方式、gcore -o 前缀陷阱、暂停代价与 ulimit 边界、离线分析入口
  • VitePress + GitHub Actions：私有笔记仓库自动发布到 GitHub Pages —— 私有仓库存源、Actions 构建、产物推公开仓库由 Pages 发布的完整链路：base 与 srcExclude 关键配置、目录递归扫描的自动侧边栏、PAT 跨仓库推送工作流与常见构建问题
  • Node.js 多版本管理：nvm、n 与 Volta —— shell 切换、全局替换、工具链固定三种思路对比，.nvmrc 与 volta pin 的项目级版本锁定、常用命令速查与选型建议
  • Linux 多版本程序管理：update-alternatives —— 两级符号链接链与优先级 auto 模式、四参数注册与交互切换、manual 固定语义，及与语言运行时专用管理器的适用边界
  • 飞书机器人控制内网 Claude Code：FRP 内网穿透与部署 —— FRP 控制与数据双通道原理、frps/frpc TOML 配置、Nginx TLS 终止与路径收口、飞书 3 秒回调的异步设计、自签证书卡死卡片回调的踩坑与分层验证
  • GDB 调试信号处理程序：handle 命令与 VSCode 集成 —— handle 三开关（stop/print/pass）与 info signals 现状查询、setupCommands 固化进 launch.json、断点加 kill 触发的信号调试流程
  • Git 全局 ignore 配置原理 —— 三种忽略来源的分工与叠加、core.excludesFile 的 XDG 默认路径、模式路径深度陷阱，check-ignore -v 验证规则来源
  • Windows 浏览器访问不可达网段：SSH SOCKS5 与 SwitchyOmega 配置 —— SSH -D 动态转发 + SwitchyOmega IP 通配符分流 + NSSM 服务化开机自启，附 SYSTEM 账户密钥路径坑与方案对比
  • Git Rebase 与 Cherry-pick 实用指南 —— 交互式 rebase 命令清单与合并部分提交、大量提交压缩的两个方案，cherry-pick 范围语法与改写历史后的 force-with-lease 推送
  • Linux 使用 Clash 代理客户端：安装、systemd 常驻与终端代理 —— 单二进制部署、config.yaml 与 GeoIP 就位、十行 systemd unit 服务化，终端环境变量代理与 git 单独配置
  • repo 多仓管理工具指南 —— Google repo 从安装到日常开发全流程，含 detached HEAD、m/ 上游变基等踩坑点，附 manifest 格式字段速查
  • Git 常用命令速查 —— 按功能分类的命令表，三棵树工作模型，pull/fetch/merge/rebase 的关系与结果图解，回滚本地与远程分支、stash 暂存详解、tag 同步被拒处理与 force-with-lease 风险控制
  • systemd 强杀服务导致配置文件损坏的排查 —— KillMode/TimeoutStopSec 停机时序复盘强杀打断写入的完整过程，附退出顺序与原子写入修复
  • Linux 网络状态查询命令速查 —— 按排查路径整理的 ip/ss/dig/mtr 等命令，含 net-tools 新旧对照与权限说明
  • zsh 历史记录损坏的修复 —— corrupt history file 报错的处理：strings 剥离坏字符重建历史，fc -R 免重启重载
  • GitHub SSH 走代理与 443 端口配置 —— ProxyCommand 过本地代理 + ssh.github.com:443 绕端口封锁，附 Windows Git Bash 的 connect 写法
  • SSH 反向隧道远程访问内网开发机配置指南 —— 内网机主动出站建反向隧道到公网 VPS，autossh+systemd 保活，Termius ProxyJump 手机直达
  • GDB attach 加载带调试信息的共享库符号 —— stripped 库的符号加载两条路线：add-symbol-file 手动附加（含 solib-search-path 失效踩坑），分离调试包的 debug-file-directory 标准用法
  • 使用 FRP 反向代理实现 Windows 远程桌面连接 —— frps/frpc 双端 TOML 配置、RDP 映射与 NSSM 服务化，v0.52+ 新写法
  • Valgrind 内存与文件描述符泄漏排查指南 —— Memcheck 与 --track-fds 两个场景的完整流程，常用选项对照官方手册核实
  • gdb 常用命令速查 —— 按功能分类的命令表，附批量打印线程栈与 ptrace 权限处理
  • Linux 定时任务：cron 与 systemd timer —— 以每日重启为例对比两种定时任务配置与适用场景
  • systemd 定时任务与服务清理 —— timer + service 的完整移除步骤与一键清理脚本
  • Doxygen 生成 C++ 类图完整配置指南 —— 从零配置 Doxyfile 生成 UML 类图，标注 1.8.x 与 1.9.x 的选项差异，附完整模板
